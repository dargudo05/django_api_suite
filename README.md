# django_api_suite

Backend desarrollado con Django que centraliza herramientas y servicios para la gestión de datos, el consumo de APIs externas y la exposición de un dashboard administrativo con renderización del lado del servidor (SSR). El objetivo del proyecto es construir una base backend estructurada y escalable, aplicando buenas prácticas de organización por aplicaciones (homepage, dashboard), uso de plantillas con herencia, archivos estáticos y consumo de servicios REST externos.
